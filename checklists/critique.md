# Critique checklist

Run this before exporting. If more than two items fail, fix before posting.

- **Hierarchy:** Can you tell what to read first, second, third in under 3 seconds?
- **Alignment:** Does every element sit on a shared edge or grid line?
- **Spacing:** Are gaps from the 4/8px scale and consistent between similar items?
- **Type:** Two typefaces maximum; body text 16px or larger on web.
- **Color:** Text passes WCAG AA contrast (4.5:1 for body text).
- **Copy:** Is the headline specific to this business, not generic?
- **CTA:** Is there exactly one obvious next action?
