# Daily content workflow

A 90-minute routine that produces one finished design piece every working day.

| Time | Step | Output |
| --- | --- | --- |
| 0-10 min | Pick the day's prompt from the rotation | One brief |
| 10-25 min | Collect references (3 max) | Moodboard |
| 25-70 min | Design | First version |
| 70-80 min | Critique against the checklist | Revised version |
| 80-90 min | Export and write the caption | Post ready to publish |

## Weekly rotation

| Day | Format |
| --- | --- |
| Monday | Website hero section |
| Tuesday | Landing page |
| Wednesday | App screen |
| Thursday | Logo or wordmark |
| Friday | Brand graphic or social post |
